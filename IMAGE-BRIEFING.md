## Reglas duras (todas las imágenes deben cumplir)

1. **NO stock corporativo de Shutterstock genérico.** Las "manos sobre el teclado" o "businesspeople sonriendo señalando una pantalla" están prohibidas.
2. **Sí gente real haciendo cosas reales.** Personas trabajando, hablando, mirando una pizarra, en un taller, en una clínica. No poses.
3. **Catalunya / Mediterráneo siempre que sea posible.** Luz natural, edificios bajos, materiales nobles (madera, ladrillo). Evitar paisajes de Silicon Valley o Manhattan.
4. **Tono coherente con el dark mode lila.** En post-procesado: ligero desaturado, con un punto de violet/magenta en sombras. La web es dark, las fotos no pueden chocar.
5. **Aspect ratios respetados.** Cada brief especifica el ratio. NO recortes brutos.
6. **Sin texto en la imagen.** La tipografía la pone la web. Si la imagen ya trae texto, descartar.
7. **Personas con cara o sin cara, ambas válidas.** Foto de espaldas, manos, perfil, también funciona y es menos arriesgado para licensing.

## Cómo entregarlas a Diego

Una vez tengamos las imágenes:

1. Colocarlas en `/Users/diego/dev/website/img/photos/` con nomenclatura del data-img:
   - `hero-main.webp`
   - `band-barcelona.webp`
   - `ind-industria.webp` ... `ind-retail.webp`
   - `proc-1.webp` ... `proc-4.webp`
   - `manifesto-bg.webp`

2. Editar `index-v5.html` reemplazando cada `<div class="imgph" data-img="X">` por:
   ```html
   <div class="imgph imgph--has" data-img="X">
     <img src="/img/photos/X.webp" alt="[descripción semántica]">
   </div>
   ```
   El `imgph--has` oculta automáticamente el placeholder.

3. Para `manifesto-bg`, sustituir el placeholder note por background-image en el CSS de `.manifesto::before`.

## Recursos de búsqueda

- **Unsplash:** https://unsplash.com (gratis, licencia muy permisiva)
- **Pexels:** https://pexels.com (gratis)
- **Canva Pro:** assets stock + generación con IA. Diego tiene Canva Pro.
- **Stocksy:** premium, ~€10-30/foto, calidad muy superior. Recomendado para las 2 críticas (hero, band).
- **Adobe Stock:** integrado con Canva. Calidad alta.
- **Sesión propia:** lo ideal para hero + team. Fotógrafo en Barcelona ~€350-500 una sesión de 1h.
